# السندباد · ALSINDBAD

تطبيق عربي وإنجليزي لإدارة حسابات ومشتريات ومخزون وحاويات فرع جدة، بواجهة تعمل على الجوال والكمبيوتر. الكود مبني بـ Next.js وTypeScript، وتُحفظ سجلات العمل والفواتير في Supabase عند ربطه.

## التشغيل

يتطلب Node.js 24 وpnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

افتح [localhost:3000](http://127.0.0.1:3000). بدون إعداد Supabase تظهر نسخة تجريبية ببيانات افتراضية. تغييرات هذه النسخة تبقى في المتصفح نفسه. جرّب تسجيل مشتريات وسداد دين وتحميل بضاعة قبل ربط بيانات العمل.

## تشغيل مساحة العمل الخاصة على Vercel

1. أنشئ مشروعًا في Supabase. نفّذ ملف [تهيئة قاعدة البيانات](supabase/migrations/202611070001_workspace.sql) مرة واحدة في SQL Editor.
2. أنشئ حساب الدخول المطلوب من **Authentication → Users**. عطّل التسجيل العام، ثم انسخ معرف الحساب من Supabase وامنحه الوصول باستخدام SQL Editor. استبدل القيمة التالية بمعرف الحساب.

   ```sql
   insert into public.workspace_members (user_id)
   values ('00000000-0000-0000-0000-000000000000');
   ```

   نسخة فرع جدة تبدأ بحساب واحد. كل حساب مصرّح به يرى سجلاته الخاصة، والحسابات المختلفة لا تشارك سجلًا واحدًا.
3. استورد مستودع [AOUGRAV/ALSINDBAD](https://github.com/AOUGRAV/ALSINDBAD) في Vercel واختر Next.js وNode.js 24. أضف متغيرَي [.env.example](.env.example) في إعدادات Vercel. استخدم عنوان مشروع Supabase ومفتاحه **Publishable** أو **anon**. للتشغيل محليًا انسخهما إلى `.env.local`.
4. بعد النشر اختبر الرابط دون تسجيل دخول، ثم اختبر تسجيل الدخول ورفع فاتورة تجريبية والتصدير من الحساب المصرّح له. خصص سجلات العمل الفعلية للمشروع الخاص.

تنطبق سياسات RLS على السجلات والمرفقات، ولا يحتاج التطبيق إلى مفتاح `service_role`. المستودع يحتوي الكود والبيانات الافتراضية. تُستبعد ملفات البيئة من Git.

## طريقة تسجيل العمليات

- **تمويل المالك** يدخل النقد دون تصنيفه كإيراد. **القرض المستلم** يزيد النقد والالتزامات. **السلفة الممنوحة** تُسجّل مبلغًا مستحقًا لنا. سجل الدفعات من بطاقة الدين بالعملة الأصلية.
- **شراء بضاعة** يسجل الصنف والكمية وإجمالي الفاتورة والمدفوع. الباقي يصبح التزامًا للمورد. أضف الصنف من المخزون قبل تسجيل الشراء.
- **مصروف** يُصنّف شخصيًا أو تجاريًا، مثل الإيجار والبنزين والإكراميات. **شراء أصل** فئة مستقلة في السجل والتقارير. يمكن ربط مصاريف النقل والشحن بالحاوية.
- **العملات** هي SAR وUSD وGBP وEUR. أدخل سعر الصرف بالريال لكل وحدة. يحسب التطبيق المعادل تلقائيًا ويحفظ السعر مع العملية. يظهر النقد بالعملة الأصلية، ويعرض ملخص الريال مكافئ الحركات وفق أسعارها المسجلة.
- **الشحن** يحجز الكمية المحمّلة من المخزون. يمكن تسجيل حالة الشحن ثم الوصول. تقدير تكلفة الحاوية يستخدم متوسط تكلفة شراء الأصناف المسجلة حاليًا مضافًا إليه المصاريف المرتبطة.
- **الفواتير** تُرفع من الجوال أو الكمبيوتر بصيغة صورة JPG/PNG/WebP أو PDF حتى 5 MB بعد إعداد Supabase. بيانات الفاتورة تُدخل يدويًا.
- **التقارير** تشمل الحركات والديون المفتوحة والمخزون وأسعار الشراء حسب المورد والتاريخ والحاويات. اختر الفلاتر ثم صدّر Excel أو استخدم زر PDF واختر «حفظ بصيغة PDF» في نافذة الطباعة.

هذه النسخة تحفظ الحركات كسجل إضافات مع وقت التسجيل. تحرير الحركات بعد حفظها، القيود العكسية، قراءة الفواتير آليًا، تسوية العملات المختلفة وإدارة دفعات المخزون حسب التشغيلة خارج نطاق الإصدار الأول.
