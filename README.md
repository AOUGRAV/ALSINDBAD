# السندباد · ALSINDBAD

مساحة العمل الخاصة بفرع جدة لإدارة الحسابات والمشتريات والمخزون والحاويات، بالعربية والإنجليزية وعلى الجوال والكمبيوتر. الواجهة مبنية بـ Next.js وTypeScript، وتُحفظ سجلات العمل والفواتير في Supabase.

## النشر من GitHub على Vercel

1. من **Add New → Project** استورد مستودع [AOUGRAV/ALSINDBAD](https://github.com/AOUGRAV/ALSINDBAD).
2. اختر **Next.js** وNode.js 24، واضبط فرع النشر على `main`. يستخدم Vercel أمر البناء من `package.json` وإعدادات الاستجابة من `vercel.json`.
3. أضف المتغيرات من [.env.example](.env.example) إلى بيئة **Production** قبل النشر. استخدم عنوان المشروع ومفتاحه **Publishable** من Supabase.
4. بعد اكتمال البناء، افتح رابط `vercel.app` من لوحة المشروع. يُعاد بناء الموقع عند رفع تحديث إلى `main`.

تقدّم الاستضافة ملفات الواجهة، ويتحقق Supabase من صلاحية الوصول إلى كل سجل ومرفق. لا يحتاج التطبيق إلى مفتاح `service_role`، وتُستبعد ملفات البيئة من Git.

## تفعيل حساب العمل

عند إعداد قاعدة بيانات جديدة، نفّذ ملفات [تهيئة قاعدة البيانات](supabase/migrations) بالترتيب. إذا طُبّقت التهيئة على مشروعك من قبل، تابع بإعداد حساب الدخول.

1. في Supabase افتح **Authentication → Users → Add user → Create new user** وأنشئ حساب العمل ببريدك وكلمة مرور تختارها هناك. يمكنك تأكيد الحساب عند إنشائه من لوحة الإدارة. عطّل التسجيل العام من إعدادات المصادقة.
2. من SQL Editor أضف معرّف الحساب الذي أنشأته إلى قائمة الوصول. استبدل القيمة التالية بمعرّف المستخدم من Supabase.

   ```sql
   insert into public.workspace_members (user_id)
   values ('00000000-0000-0000-0000-000000000000')
   on conflict (user_id) do nothing;
   ```

مساحة فرع جدة تستخدم حساب العمل المصرّح له. الحسابات المختلفة معزولة عن بعضها. المرفقات في حاوية تخزين خاصة، وتُعرض بعد تسجيل الدخول والتحقق من الصلاحية.

## التشغيل المحلي

يتطلب Node.js 24 وpnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

انسخ متغيرات [.env.example](.env.example) إلى `.env.local` قبل التشغيل. افتح [localhost:3000](http://127.0.0.1:3000). مسار العمل يتطلب حساب Supabase المصرّح له.

## طريقة تسجيل العمليات

- **تمويل المالك** يدخل النقد دون تصنيفه كإيراد. **القرض المستلم** يزيد النقد والالتزامات. **السلفة الممنوحة** تُسجّل مبلغًا مستحقًا لنا. فعّل «دين سابق قبل بدء التسجيل» لترحيل دين قائم دون تسجيل حركة نقدية جديدة. سجل الدفعات من بطاقة الدين بالعملة الأصلية.
- **شراء بضاعة** يسجل الصنف والكمية وإجمالي الفاتورة والمدفوع. الباقي يصبح التزامًا للمورد. أضف الصنف من المخزون قبل تسجيل الشراء.
- **مصروف** يُصنّف شخصيًا أو تجاريًا، مثل الإيجار والبنزين والإكراميات. **شراء أصل** فئة مستقلة في السجل والتقارير. يمكن ربط مصاريف النقل والشحن بالحاوية.
- **العملات** هي SAR وUSD وGBP وEUR. أدخل سعر الصرف بالريال لكل وحدة. يحسب التطبيق المعادل تلقائيًا ويحفظ السعر مع العملية. يظهر النقد بالعملة الأصلية، ويعرض ملخص الريال مكافئ الحركات وفق أسعارها المسجلة.
- **الشحن** يحجز الكمية المحمّلة من المخزون. تثبَّت تكلفة البضاعة وفق متوسط تكلفة الصنف عند التحميل، وتضاف إليها المصاريف المرتبطة. يمكن تسجيل حالة الشحن ثم الوصول.
- **الفواتير** تُرفع من الجوال أو الكمبيوتر بصيغة JPG/PNG/WebP أو PDF حتى 5 MB. زر القراءة يقترح الإجمالي والتاريخ والعملة ورقم الفاتورة والمورد عندما يتعرّف عليها. تتم القراءة في المتصفح. راجع الحقول قبل الحفظ وأدخل الصنف والكمية بنفسك.
- **التصحيح والإلغاء** من إدارة الحركة في السجل. يتطلب التغيير سببًا، ويحفظ النظام نسخة الحركة السابقة ووقت التعديل. الحركات الملغاة تبقى قابلة للعرض من السجل وتُستبعد من الأرصدة والتقارير.
- **التقارير** تشمل الحركات والديون المفتوحة والمخزون وأسعار الشراء حسب المورد والتاريخ والحاويات. اختر الفلاتر ثم صدّر Excel أو استخدم زر PDF واختر «حفظ بصيغة PDF» في نافذة الطباعة.
